# Tractor Field Guide 0.5

## Новое в 0.5
- Количество видимых GNSS-спутников.
- Количество спутников, реально используемых в фиксации координат.
- Оценка точности GPS в метрах.
- Текстовая оценка качества: отлично / очень хорошо / хорошо / средне / плохо.
- Фильтрация плохих GPS-точек.
- Отбрасывание очевидных скачков координат.
- Счётчик отброшенных GPS-точек.
- Подготовлена архитектура под отдельный источник координат: внешний Bluetooth GNSS/RTK.

## Важно
Количество спутников само по себе не гарантирует сантиметровую точность. Для точного параллельного вождения нужен хороший GNSS/RTK-приёмник и корректировки RTK.

## Следующий модуль
- Bluetooth-подключение внешнего GNSS/RTK.
- Приём NMEA-потока.
- Отображение RTK Float / RTK Fix.
- Переключение источника координат: Телефон / Внешний GNSS.
- Использование внешних координат во всех режимах навигации.
