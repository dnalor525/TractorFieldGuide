# Как получить установочный APK

Проект уже настроен для автоматической сборки APK.

## Самый простой способ через компьютер
1. Установить Android Studio.
2. Открыть папку TractorFieldGuide.
3. Дождаться Gradle Sync.
4. Выбрать Build → Build APK(s).
5. Готовый файл будет:
   app/build/outputs/apk/debug/app-debug.apk

## Автоматическая сборка через GitHub
1. Создать бесплатный репозиторий GitHub.
2. Загрузить содержимое папки TractorFieldGuide в репозиторий.
3. Открыть вкладку Actions.
4. Выбрать Build Android APK → Run workflow.
5. После завершения открыть Artifacts → TractorFieldGuide-debug-apk.
6. Скачать app-debug.apk на телефон и установить.

## На Android
При первом запуске дать приложению доступ к точной геолокации.
Если Android блокирует APK, разрешить установку приложений из этого источника для браузера/файлового менеджера.

Примечание: это тестовая debug-версия приложения.
